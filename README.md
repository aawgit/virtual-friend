# ARKit Blendshape Visualizer

A React application for visualizing ARKit blendshape coefficients on a 3D face model.

## Features

- Parse and visualize ARKit blendshape coefficients
- Interactive 3D model viewer with Three.js
- Sliders for manual adjustment of blendshape values
- Statistics display for active blendshapes
- Responsive design for desktop and mobile

## Getting Started

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser and navigate to the local server URL (usually http://localhost:5173)

## Usage

1. Paste an array of ARKit blendshape coefficients in the input area
2. Click "Parse & Apply Blendshapes" to visualize them on the 3D model
3. Use the sliders to manually adjust individual blendshape values
4. View statistics about your blendshape data

## Technologies Used

- React
- Three.js
- Vite
